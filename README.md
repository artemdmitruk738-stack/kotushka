# Котушка — музичний PWA-плеєр (Spotify + SoundCloud)

## Що вже працює
- Вхід через Spotify (PKCE, без бекенду)
- Пошук треків у Spotify — натискання відкриває трек у самому Spotify (застосунку або сайті), де він грає безкоштовно, як завжди
- Додавання треків SoundCloud за посиланням (через публічний oEmbed) — **грають прямо всередині "Котушки"**, без обмежень
- Особиста бібліотека "Моя котушка" (зберігається в localStorage телефону)
- Повноекранний плеєр з лічильником-прогресом у стилі касети — працює для SoundCloud-треків
- Встановлення на головний екран телефону як застосунок (PWA)

## Обмеження, про які варто знати
- **Spotify-треки не грають усередині застосунку** — Spotify Web Playback SDK технічно вимагає Premium-акаунт, тож замість вбудованого програвання натискання на трек відкриває його в самому Spotify. Якщо колись оформиш Premium — про це можна писати, і я поверну повноцінне відтворення в застосунку.
- **SoundCloud без пошуку всередині застосунку** — офіційний API закритий для нових розробників з 2022 року. Працює тільки додавання за прямим посиланням на трек (Поділитись → Копіювати посилання в самому SoundCloud).
- Музика не грає, поки немає інтернету — сервіс-воркер кешує тільки саму "оболонку" застосунку.

## Крок 1. Створи застосунок у Spotify
1. Зайди на https://developer.spotify.com/dashboard і увійди своїм акаунтом Spotify.
2. Натисни **Create app**.
3. У полі **Redirect URI** встав точну адресу, за якою будеш хостити застосунок (наприклад `https://твій-нікнейм.github.io/kotushka/`). Це критично — має збігатись символ-в-символ.
4. Онови застосунок, скопіюй **Client ID**.

## Крок 2. Встав Client ID у код
Відкрий файл `config.js` і заміни:
```js
SPOTIFY_CLIENT_ID: "ВСТАВ_СВІЙ_CLIENT_ID_СЮДИ",
```
на свій реальний Client ID.

## Крок 3. Виклади застосунок в інтернет
Spotify вимагає HTTPS-адресу (localhost для тестів теж підходить). Найпростіший безкоштовний варіант — **GitHub Pages**:
1. Створи новий репозиторій на GitHub, назви його наприклад `kotushka`.
2. Заливи туди всі файли з цієї папки.
3. У налаштуваннях репозиторію → **Pages** → постав джерело `main` branch, папка `/root`.
4. Через хвилину застосунок зʼявиться за адресою `https://твій-нікнейм.github.io/kotushka/`.
5. Переконайся, що ця адреса **точно** співпадає з Redirect URI, який ти вписав у Spotify Dashboard на Кроці 1.

Альтернатива — Vercel або Netlify (перетягни папку в їхній інтерфейс, теж безкоштовно і теж з HTTPS одразу).

## Крок 4. Встанови на телефон
Відкрий адресу застосунку в Safari (iPhone) або Chrome (Android):
- **iPhone:** кнопка "Поділитись" → "На екран Домівки"
- **Android:** меню (три крапки) → "Додати на головний екран"

## Що можна доробити далі (коли освоїшся з JS)
- Плейлисти власного складу (зараз є тільки один спільний список "Моя котушка")
- Перетягування треків для зміни порядку
- Кнопки "далі/назад" по черзі в бібліотеці (зараз вони є в інтерфейсі, але не підключені до логіки — гарна вправа, щоб потренуватись)
- Офлайн-повідомлення, коли немає інтернету
